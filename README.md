# Excel Data Analysis & Interactive Dashboards

This repository contains a collection of **data analysis projects and interactive dashboards created using Microsoft Excel**. Each project involves analyzing a dataset, creating pivot tables, generating insights, and designing an interactive dashboard to present the results visually.

## Projects Included

- **IPL Interactive Dashboard** – An interactive dashboard for analyzing IPL-related data and exploring key statistics and trends.
- **Netflix Dashboard** – A data analysis dashboard based on Netflix-related data, providing insights through interactive visualizations.
- **COVID-19 Dashboard** – An interactive dashboard for analyzing COVID-19 data and presenting important trends and statistics.
- **Customer Profile Dashboard** – Analyzes customer-related data to identify patterns and characteristics using interactive visualizations.
- **Sales Data Analysis** – Analyzes sales data using Excel tools to identify trends, patterns, and key business insights.
- **Sales Interactive Dashboard** – An interactive dashboard designed to visualize and explore sales performance and related metrics.
- **Student Career Dashboard** – Analyzes student and career-related data to explore trends and insights.
- **Worldwide Importers Dashboard** – Analyzes worldwide importer data and presents the results through an interactive Excel dashboard.
